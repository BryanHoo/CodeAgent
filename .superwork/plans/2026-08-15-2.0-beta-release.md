# Feature Implementation Plan

**Goal:** 通过受保护 PR、真实 Desktop IPC E2E、三平台最低系统 smoke 与首发 Updater 验收，发布 `v2.0.0-beta.1`。

**Suggested Spec Reads:**

- `.superwork/spec/guides/index.md` — 约束版本单一来源、三平台矩阵、Updater 签名和发布顺序。
- `.superwork/spec/frontend/quality-guidelines.md` — 约束 Desktop Transport 与真实宿主测试。
- `.superwork/spec/shared/quality-guidelines.md` — 约束 IPC 契约、错误透传与跨平台测试。
- `.superwork/prd/2026-08-15-2.0-beta-release-design.md` — 固定已选方案、首发 bootstrap 边界和 GitHub 治理策略。
- `docs/tauri-migration-plan.md` — 定义 Phase 9、Desktop E2E 与 clean VM 验收范围。

**Architecture:** 使用 feature-gated embedded WebDriver 启动真实 Tauri binary；release workflow 先创建 draft，再串行依赖三端 smoke、自动 Updater bootstrap 验收和受保护 Environment，最后以 npm `beta` dist-tag 发布并公开 GitHub Release。

**Tech Stack:** TypeScript、WebdriverIO、Rust 2024、Tauri v2、GitHub Actions、PowerShell、Node.js 24、pnpm、GitHub CLI

## Global Constraints

- 正式 Desktop binary 不得包含 WebDriver server、测试 capability 或调试后门。
- Desktop 与 CLI 只支持 macOS 14+ Apple Silicon、Windows 10+ x64、Ubuntu 22.04+ x64 glibc。
- 三平台保持 Preview / Unsigned，但 Tauri updater artifact 必须继续使用现有密钥签名。
- npm prerelease 只发布到 `beta`，不得移动 `latest`。
- 缺少真实 Windows 10 runner、任一 smoke 或 Updater 验收失败时保持 draft，禁止发布 npm。
- 单文件不得超过 500 行；性能和有界清理优先；不启动开发服务器。
